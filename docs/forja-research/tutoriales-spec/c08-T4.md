# c08 — Tutorial 4 (Fusion 360: A Tutorial Approach, CADCIM)

> AVISO IMPORTANTE: Este Tutorial 4 del Capitulo 8 **NO es un tutorial de modelado por
> croquis/extrude**. Es un tutorial del **ANIMATION Workspace**: crear una animacion de
> **vista explosionada lineal (linear explode)** del ensamble **Bench Vice** y exportarla
> como archivo `.avi`. NO hay sketch, NO hay cotas de croquis, NO hay operacion 3D
> (extrude/revolve). Los unicos "numeros" del tutorial son distancias de explosion de
> componentes ya modelados. La Forja (CAD web de croquis→feature) NO puede reproducir
> este tutorial por clicks de dibujo, porque no dibuja nada.

## objetivo
Animar el ensamble **Bench Vice**: una explosion lineal de sus componentes (tornillos,
placas, globos de barra, etc.) sobre la ANIMATION TIMELINE, y guardar la animacion como
`.avi` con el nombre "Bench Vice assembly". (Tiempo estimado del libro: 45 min.)

Pasos macro del libro:
- a. Abrir el Data Panel.
- b. Invocar el ANIMATION Workspace.
- c. Crear una Animating View.
- d. Animar el ensamble.

## setup
- No pide unidades ni grid/snap (no hay croquis). El libro solo abre un ensamble existente.
- Requiere tener el ensamble **Bench Vice Assembly** (carpeta CADCIM) ya modelado y ensamblado.

## pasosDibujo
NO APLICA. Este tutorial no dibuja croquis. En su lugar, la secuencia de acciones de
animacion (literal del libro) es:

**Abrir Data Panel y ensamble**
1. Click en Data Panel (Application menu).
2. Doble-click en carpeta CADCIM y abrir Bench Vice Assembly.

**Invocar ANIMATION Workspace**
1. Elegir ANIMATION Workspace del drop-down de Workspaces (Figura 8-26).

**Crear la Animating View**
1. Arrastrar el Playhead de la ANIMATION TIMELINE a la Scratch Zone (fija estado inicial sin grabar).
2. Boton Home del ViewCube → vista isometrica (Figura 8-26).
3. Arrastrar el Playhead a ~2 segundos en la ANIMATION TIMELINE.
4. Rotar el ensamble para ver la parte inferior; seleccionar TODOS los tornillos con Ctrl (Figura 8-27).
5. Click derecho en el tornillo en el BROWSER → menu contextual.
6. Elegir Transform Components → aparece dialogo TRANSFORM COMPONENTS + triada.
7. Seleccionar el vector direccion de la triada en el eje **Z** → aparece Z Distance.
8. Escribir **70** en Z Distance → los tornillos se explotan hacia abajo (Figura 8-28).
9. Boton Trail Line Visibility → se muestra el rastro (trail).
10. OK.
11. Herramienta Transform Components (panel TRANSFORM del Ribbon).
12. Seleccionar **Base Plates** y **Clamping Plate** con Ctrl.
13. Seleccionar vector direccion de la triada → aparece Z Distance.
14. Escribir **-50** en Z Distance → se explotan.
15. Shift+click en Base Plate y Clamping Plate uno por uno para liberarlos del set de seleccion.
16. Seleccionar **Bar Globes, Screw Bar y Jaw Screw** → se muestran en azul con triada.
17. Seleccionar vector direccion → aparece X Distance.
18. Escribir **80** en X Distance → se explotan. Liberar con Shift (Figura 8-29).
19. Boton Trail Line Visibility.
20. OK.
21. Invocar de nuevo TRANSFORM COMPONENTS y seleccionar **Oval Fillister**.
22. Seleccionar vector direccion **Z** → aparece Z Distance.
23. Escribir **60** en Z Distance → se explota. Liberar Oval Fillister con Shift.
24. Boton Trail Line Visibility.
25. Elegir **Vice Jaw** y escribir **40** en Z Distance → se explota en Z (Figura 8-30).
26. Boton Trail Line Visibility.
27. OK.
28. Igual, explotar los **Bar Globes** uno por uno en direccion **Y** (Figura 8-31).

**Animar el ensamble**
1. Play Current Storyboard → los componentes se mueven en el mismo orden que se explotaron.
2. Back to Storyboard Beginning → se re-ensamblan.
3. PUBLISH (panel PUBLISH del Ribbon) → dialogo Video Options (Figura 8-32).
4. Video Scope: opcion Current Storyboard.
5. Window size: opcion Custom (Video Resolution).
6. Especificar Width y Height (el libro remite a la Figura 8-32; no da los numeros exactos en texto).
7. Marcar Lock Aspect Ratio.
8. OK → aparece Save As.
9. Escribir el nombre del ensamble en Name.
10. Marcar "Save to a project in the cloud" y elegir proyecto CADCIM.
11. Save.

## medidasFigura
No hay figura de croquis acotado. Las unicas cantidades numericas del tutorial son las
distancias de explosion de componentes:
- Tornillos (screws): Z = **70**
- Base Plates + Clamping Plate: Z = **-50**
- Bar Globes + Screw Bar + Jaw Screw: X = **80**
- Oval Fillister: Z = **60**
- Vice Jaw: Z = **40**
- Bar Globes (individuales): direccion **Y** (el libro NO da valor numerico exacto)

## herramientasFaltantes
La Forja NO tiene lo que este tutorial necesita, porque es de animacion, no de CAD de croquis:
- ANIMATION Workspace / ANIMATION TIMELINE + Playhead + Scratch Zone.
- Transform Components (explosion de componentes con triada y ejes X/Y/Z).
- Trail Line Visibility (rastros de explosion).
- Ensamblaje multi-componente con BROWSER de componentes.
- PUBLISH / export de video (.avi) con Video Options (scope, resolucion, aspect ratio).
- Requiere el ensamble Bench Vice ya modelado (dependencia de tutoriales previos).

## formaFinal
No hay una nueva forma 3D que verificar. El "resultado" es un **video de explosion**: el
ensamble Bench Vice se desarma linealmente (tornillos hacia abajo, placas, globos, jaw
screw, oval fillister, etc.) mostrando rastros, y luego se re-ensambla. Entregable = archivo
`.avi` "Bench Vice assembly".

### Conclusion para el proceso reproductor
Este spec NO es reproducible por La Forja como tutorial de modelado por clicks. Si el
objetivo era un tutorial de sketch→extrude/revolve, se eligio el tutorial equivocado:
Capitulo 8 Tutorial 4 es de animacion (exploded view). Recomendacion: usar otro tutorial de
un capitulo de modelado de piezas (croquis + feature) para la reproduccion por clicks.
