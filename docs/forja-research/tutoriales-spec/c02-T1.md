# Spec literal — Capitulo 2, Tutorial 1

Fuente: "Autodesk Fusion 360: A Tutorial Approach" (CADCIM), c02, Tutorial 1.
Extraccion literal del texto + Figuras 2-3 (croquis acotado) y 2-4 (modelo iso).
Nombre del modelo del libro: `c02_Tut_01`.

> Todos los numeros son LITERALES del libro. Donde el libro es ambiguo, se marca
> con [OJO] y se explica la lectura correcta segun la Figura 2-3.

---

## objetivo
Dibujar el croquis de la Figura 2-3 (perfil tipo viga-I / doble-T con una cavidad
rectangular pasante en el alma), **extruirlo 20 mm** y luego generar un plano con
vistas ortograficas + isometrica. El perfil tiene DOS lazos: lazo exterior (viga-I)
+ lazo interior (rectangulo) que al extruir se resta y crea la cavidad.

## setup
- Unidades: **Millimeter** (mm es el default de Fusion).
- Plano de croquis: **XY Plane (Front plane)** bajo el nodo Origin.
- Grid/Snap para que el cursor salte cada **5 mm**:
  - Grid Settings → radio button **Fixed**.
  - **Major Grid Spacing = 100**
  - **Minor Subdivision = 20**
  - (ratio 100/20 = 5 mm por salto)
  - **Snap to Grid** activado.
- Se usa **Dynamic Input** (campos longitud + Tab + angulo) para todo el croquis.

## pasosDibujo

### Lazo exterior — herramienta Line (empieza en el origen)
El origen queda en el **punto medio de la arista inferior**. Secuencia de cadena
continua (mover cursor en la direccion indicada, escribir longitud, Tab, angulo, Click):

1. Line 1: mover **derecha**, `40` Tab `0`
2. Line 2: mover **arriba**, `10` Tab `90`
3. Line 3: mover **izquierda**, `15` Tab `90`
4. Line 4: mover **arriba**, `30` Tab `90`
5. Line 5: mover **derecha**, `15` Tab `90`
6. Line 6: mover **arriba**, `10` Tab `90`
7. Line 7: mover **izquierda**, `80` Tab `90`
8. Line 8: mover **abajo**, `10` Tab `90`
9. Line 9: mover **derecha**, `15` Tab `90`
10. Line 10: mover **abajo**, `30` Tab `90`
11. Line 11: mover **izquierda**, `15` Tab `90`
12. Line 12: mover **abajo**, `10` Tab `90`
13. Line 13: mover **derecha**, `40` Tab `90`  (cierra en el origen)
14. Right-click → Marking menu → **OK** (termina la cadena).

> [NOTA] El libro escribe el angulo `90` en casi todos los tramos (2-13). En Dynamic
> Input de Fusion ese `90` es el angulo RELATIVO al segmento anterior (giro de 90°),
> no absoluto. Line 1 usa `0` (horizontal). La direccion del "mover cursor" define
> hacia donde. Coordenadas absolutas resultantes desde el origen (0,0):
> (0,0)→(40,0)→(40,10)→(25,10)→(25,40)→(40,40)→(40,50)→(-40,50)→(-40,40)
> →(-25,40)→(-25,10)→(-40,10)→(-40,0)→(0,0). Cierra exacto (Δx=0, Δy=0).

### Lazo interior — herramienta Center Rectangle
15. SKETCH → CREATE → Rectangle → **Center Rectangle**.
16. Desde el origen, mover el cursor **verticalmente hacia arriba 5 unidades** y Click
    para fijar el centro del rectangulo.
    > [OJO] "5 units" = 5 CELDAS de grid = 5 × 5 mm = **25 mm** hacia arriba.
    > La Figura 2-3 confirma que el centro de la cavidad esta a y=25 (cavidad de
    > 15 mm sobre la arista inferior). NO son 5 mm.
17. Escribir `30` (horizontal) y `20` (vertical) en Dimension Input, Click.
18. Right-click → Marking menu → **OK**. Croquis terminado (Figura 2-12).
19. **FINISH SKETCH**.

## restricciones
- El libro NO aplica restricciones geometricas manuales (tangent/equal/symmetric/etc.)
  en este tutorial. Todo se posiciona por Dynamic Input + Snap to Grid.
- Fusion agrega restricciones automaticas (horizontal/vertical/coincident) de forma
  implicita al dibujar con snap; el libro no las lista.

## cotas (Sketch Dimension)
- El tutorial **NO acota el croquis** manualmente ("You do not need to dimension the
  drawing"). Las medidas se logran por la longitud escrita en Dynamic Input, no por
  cotas parametricas. Las cotas de la Figura 2-3 son solo de referencia.

## feature3D
- **Extrude** del perfil (lazo exterior menos lazo interior):
  - Herramienta Extrude (CREATE panel).
  - Como hay 2 lazos, el perfil NO se autoselecciona: mover el cursor **fuera del lazo
    interior pero dentro del exterior**, Click en la zona resaltada.
  - **Distance = 20** mm.
  - OK. (La cavidad rectangular queda pasante por la resta del lazo interior.)
- Guardar como `c02_Tut_01`.

## planos (drawing views)
Si — el tutorial SI pide generar el plano:
- Workspaces → **DRAWING → From Design**.
- CREATE DRAWING dialog: radio **Manual**; Contents = **Full Assembly**;
  Standard = **ISO**; Sheet Size = **A3 (420mm × 297mm)** → OK.
- Colocar la vista base (front) abajo-izquierda de la hoja.
- **Projected View**: desde la front (vista padre) generar:
  - vista **superior (top)** — cursor hacia arriba,
  - vista **lateral derecha (right-side)**,
  - vista **isometrica**.
- Right-click → OK. (Figura 2-15.)

## herramientasFaltantes (honesto — que podria no tener La Forja)
- **Dynamic Input estilo Fusion** (campo longitud + Tab + angulo relativo al segmento
  previo). Es el corazon de la captura de este tutorial; si La Forja no lo tiene, hay
  que emularlo o traducir cada linea a coordenadas absolutas (ya calculadas arriba).
- **Snap to Grid con Major/Minor configurables** (salto de 5 mm). Necesario para el
  paso "mover 5 unidades = 25 mm" del Center Rectangle.
- **Center Rectangle** (rectangulo por centro + esquina). Si solo hay 2-Point Rectangle,
  colocar el centro en (0,25) y dar esquinas en (-15,15) y (15,35).
- **Extrude de un perfil con lazo interior que auto-resta** (seleccion de region entre
  dos lazos) — clave para la cavidad. Requiere deteccion de regiones/profiles cerrados.
- **DRAWING workspace** completo (From Design, Projected View, hoja A3, iso + orto).
  Es el modulo de planos; La Forja tiene drawing.ts (3D→2D HLR) pero falta el flujo de
  hoja/vistas proyectadas/iso al estilo del tutorial.
- No requiere: fillet de croquis, 3-point arc, ni inferencing (esos aparecen en los
  Tutoriales 2, 3 y 4, no en el 1).
