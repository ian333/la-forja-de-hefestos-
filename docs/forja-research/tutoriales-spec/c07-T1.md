# c07 — Tutorial 1: Bench Vice (Ensamble bottom-up)

> Fuente: Autodesk Fusion 360: A Tutorial Approach (CADCIM), Capítulo 7, Tutorial 1.
> Texto literal en `c07_fusion_360.txt` líneas 26–176. Figuras 7-1 a 7-6 (imágenes 216–221 de OEBPS/Images).

## ⚠️ Aviso importante (honestidad)
Este **NO es un tutorial de croquis→extrude de una sola pieza**. Es un tutorial de **ENSAMBLE
bottom-up**: se construyen 10 componentes por separado (como archivos independientes) y luego
se ensamblan con **Joints**, **Contact Sets** e **Interference analysis**.

El libro **NO da el guion literal por clicks del croquis de cada componente**. Solo dice
(paso 2 de "Creating the Components", línea 45): *"Create Base of the Bench Vice assembly on
the desired plane using the dimensions given in Figure 7-3."* — es decir, remite a las figuras
acotadas y espera que el usuario ya sepa dibujar. Toda la parte "por clicks" que hay en el libro
es la del **ensamble** (qué caras/aristas seleccionar y qué tipo de joint). Las medidas de cada
pieza SÍ están completas en las figuras (abajo).

Por eso, para reproducir "por clicks" en La Forja hay dos caminos: (a) reproducir el flujo de
ensamble tal como lo narra el libro, o (b) inferir los croquis de cada pieza desde las cotas de
las Figuras 7-3 a 7-6 (esas cotas son exactas y están todas transcritas aquí).

---

## Objetivo
Crear los componentes de un **Bench Vice** (prensa de banco) y ensamblarlos (Figura 7-1). Vista
explosionada en Figura 7-2. Enfoque **bottom-up**: cada pieza es un archivo separado. Tiempo
estimado del libro: 3 h 30 min.

## Pasos macro del tutorial (líneas 30–35)
a. Crear todos los componentes del ensamble como cuerpos separados.
b. Insertar componentes en el diseño.
c. Ensamblar los componentes usando **Joints**.
d. Crear **contact sets**.
e. Analizar la **interferencia**.
f. Guardar el ensamble.

## Setup / carpetas (líneas 36–40)
- Crear carpeta `C07` bajo `CADCIM` en el Data Panel.
- Dentro de `C07`, crear carpeta `Bench Vice Assembly`. Ahí se guardan todas las piezas.
- Unidades: mm (todas las cotas de las figuras están en mm; el libro no cambia unidades explícitamente).
- El libro no especifica valores de grid/snap para este tutorial.

## feature3D

## Ensamble (esto SÍ es literal, "por clicks") — líneas 52–176

**Insertar Base (grounded):**
1. Data Panel ▸ doble-clic en `Bench Vice Assembly`.
2. Clic derecho en `Base` ▸ **Insert into Current Design** ▸ aparece MOVE/COPY ▸ dejar en default ▸ OK.
   La Base queda **grounded** (icono de push pin). Si no, clic derecho ▸ **Ground**.

**Vice Jaw — Slider joint (X):**
1. Insertar `Vice Jaw` (Insert into Current Design), reposicionar con triad si hace falta (Fig 7-9).
2. **Joint** tool (panel ASSEMBLE) ▸ pestaña **Position**.
3. Component 1: modo **Simple** ▸ elegir punto en Vice Jaw (Fig 7-11).
4. Component 2: elegir punto en Base (Fig 7-12).
5. Pestaña **Motion** ▸ Type = **Slider** ▸ Slide = **X Axis** ▸ OK. (Fig 7-14/7-15)

**Contact Set Base–Vice Jaw:**
1. **Enable All Contact** (panel ASSEMBLE).
2. Clic derecho en nodo `Contact: sets` ▸ **New Contact Set**.
3. Seleccionar `Base` y `Vice Jaw` ▸ OK.

**Jaw Screw — Cylindrical (Z) + Revolute:**
1. Insertar `Jaw Screw`, reposicionar (evitar solape) ▸ OK.
2. **Joint** ▸ Component 1 modo **Simple** ▸ punto en Jaw Screw (Fig 7-16).
3. Component 2: punto en Vice Jaw (Fig 7-17).
4. Motion ▸ Type = **Cylindrical** ▸ Axis = **Z Axis** ▸ OK.
5. Fijarlo linealmente: Joint ▸ Simple ▸ seleccionar cara del Jaw Screw (Fig 7-18) ▸
   Component 2 Select ▸ punto en Vice Jaw (Fig 7-19) ▸ aparece message box (Fig 7-20) ▸ **Continue**.
6. Motion ▸ Type = **Revolute** ▸ OK. (Fig 7-21)

**Oval Fillister — Rigid:**
1. Insertar `Oval Fillister`, reposicionar sin solape.
2. **Joint** ▸ Component 1 = cara del Oval Fillister (Fig 7-22); Component 2 = cara interior del Vice Jaw (Fig 7-23).
3. Motion ▸ Type = **Rigid** ▸ OK.

**Screw Bar — Slider (Z) + Bar Globes ×2 Rigid:**
1. Insertar `Screw Bar`, reposicionar.
2. **Joint** ▸ Comp1 = cara del Screw Bar (Fig 7-24); Comp2 = cara cilíndrica del agujero del Jaw Screw (Fig 7-25).
3. Motion ▸ Type = **Slider** ▸ Slide = **Z Axis** ▸ OK.
4. Insertar **2 instancias** de `Bar Globes`; orientar cara plana hacia el Screw Bar.
5. **Joint** ▸ Comp1 = superficie cilíndrica del Bar Globe (Fig 7-26); Comp2 = arista circular del Screw Bar (Fig 7-27) ▸ Motion **Rigid** ▸ OK.
6. Repetir Rigid para el segundo Bar Globe en el otro extremo (Fig 7-28).
7. **New Contact Set** entre Screw Bar, Jaw Screw y ambos Bar Globes ▸ OK.

**Clamping Plate — Rigid:**
1. Insertar `Clamping Plate`, reposicionar (ref Fig 7-2).
2. **Joint** ▸ Comp1 = arista circular del agujero del Clamping Plate (Fig 7-29); Comp2 = arista circular interior del agujero del Vice Jaw (Fig 7-30) ▸ Motion **Rigid** ▸ OK.

**Screw 1 (Set Screw 1) — Rigid ×2:**
1. Insertar `Screw 1`, reposicionar.
2. **Joint** ▸ Comp1 = arista circular de Screw 1 (Fig 7-31); Comp2 = arista circular del agujero del Clamping Plate, girando con ViewCube (Fig 7-32) ▸ **Rigid** ▸ OK.
3. Repetir para el otro agujero del Clamping Plate.

**Base Plate — Rigid (×2 aristas, ×2 instancias):**
1. Insertar `Base Plate`, reposicionar.
2. **Joint**: Comp1 = arista circular del agujero del Base Plate (Fig 7-33); Comp2 = arista circular del agujero de la Base con ViewCube (Fig 7-34) ▸ **Rigid** ▸ OK.
3. Repetir Rigid entre la otra arista del Base Plate y la Base.
4. Repetir todo el procedimiento para la segunda instancia de Base Plate.

**Screw 2 (Set Screw 2) — Rigid:**
1. Insertar `Screw 2` ▸ **Joint**: Comp1 = arista circular de Screw 2 (Fig 7-35); Comp2 = arista circular del agujero del Base Plate con ViewCube (Fig 7-36) ▸ **Rigid** ▸ OK.
2. Repetir para las demás instancias de Screw 2. (Ensamble completo: Fig 7-37)

## Interferencia (INSPECT) — líneas 166–171

## formaFinal
Prensa de banco (bench vice) ensamblada: una **Base** en forma de bloque con muesca en V/arco
(R16, Ø16, ranura de guía) montada sobre **2 Base Plates** largas (144) atornilladas por debajo con
**Set Screws**; sobre la Base desliza el **Vice Jaw** (mordaza, misma silueta R16/50°); un **Jaw
Screw** (husillo Ø18 cabeza, Ø16 cuerpo, 138 largo) pasa por la mordaza y gira/traslada; una manija
**Screw Bar** (104) atraviesa la cabeza del husillo con una **Bar Globe** (perilla Ø12) en cada
extremo; una **Clamping Plate** (32×32×7) sujeta con **Oval Fillister** y set screws. Ver Figura 7-1.
