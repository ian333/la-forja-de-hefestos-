# c08 — Tutorial 1 (Fusion 360: A Tutorial Approach, CADCIM)

> **AVISO IMPORTANTE (leer primero):** Este Tutorial 1 del Capítulo 8 **NO construye un
> modelo ni dibuja un croquis**. Es un tutorial del **Drawing workspace**: genera las
> **vistas de plano 2D** (front, top, right/aligned section, detail, isometric) de un modelo
> que **ya existe** — el creado en **Tutorial 4 del Capítulo 4**. Por eso NO hay
> `pasosDibujo`, `restricciones`, `cotas` de croquis ni `feature3D`. Si La Forja quiere
> reproducir este tutorial "por clicks", lo que necesita es el **módulo de planos (drawing)**,
> no el sketcher. El modelo de origen (con sus medidas) está en el spec de c04-T4, NO en este
> capítulo. Todo lo que sigue es LITERAL del libro; lo que no está, lo digo.

## objetivo
Generar las vistas de plano (front, top, right, aligned section, detail e isometric) del
modelo creado en el Tutorial 4 del Capítulo 4, usando el formato de hoja **A4 estándar**.
Operación principal: **Drawing workspace** (Base view + Projected View + Section View +
Detail View). No hay extrude/revolve en este tutorial. (Tiempo estimado del libro: 30 min.)

## setup (valores literales del libro)
- Iniciar drawing: **DESIGN workspace drop-down → Drawing From Design** → abre diálogo
  **CREATE DRAWING** (Figura 8-1 / 8-2).
- **Standard:** ISO (seleccionar si no está por defecto).
- **Sheet Size:** A4 (297mm X 210mm).
- **Orientation:** Landscape → OK. Se invoca el DRAWING workspace y aparece el diálogo
  **DRAWING VIEW** (Figura 8-3).
- Preferences (Account Settings and Preference → Preference → nodo General → Drawing,
  Figura 8-4):
  - **Standard:** ISO
  - **Units:** mm
  - Marcar **Override or Restore Format Defaults Below** (activa Project Angle).
  - **Project Angle:** Third Angle.
  - Apply → OK.

## planos (drawing views) — ESTA es la sustancia del tutorial

### 1. Vista padre (front) y vistas proyectadas
1. En DRAWING VIEW: **Orientation = Front**; botón **Visible and Hidden Edges** (adyacente a Style).
2. **Scale = 1:4**.
3. Colocar clic en el **centro-izquierda** de la hoja (Figura 8-5). OK → se genera la front view.
4. Tool **Projected View** (panel CREATE): seleccionar la front view como padre; mover el
   cursor **arriba** y colocar → **top view** (Figura 8-5).
5. Con la front view aún de padre, mover cursor **horizontal a la derecha y luego arriba** →
   preview de la **isometric view**; colocar punto.
6. Clic derecho → **OK** desde el marking menu. (Figura 8-5.)
   - Nota del libro: front y top van en estilo **Visible and Hidden Edges**; la isometric va
     en **Visible Edges**. Para cambiar estilo: doble clic en la vista → Drawing View dialog →
     Style.

### 2. Aligned Section View (usando la tool Section View)
1. Tool **Section View** (panel CREATE): seleccionar la **top projected view** como padre.
2. Mover cursor sobre la top view; el cursor hace **snap** a un punto (Figura 8-6). Clic =
   punto de inicio de la línea de sección.
3. Mover **verticalmente hacia abajo** (Figura 8-7); clic = segundo punto de la línea de
   sección → se crea la reference line.
4. Clic derecho → **Continue** (marking menu) → preview de la section view en el cursor.
5. Colocar la section view **a la derecha de la top view** (Figura 8-8). Enter.
   - (El hatching no se muestra en el preview.)

### 3. Modificar el hatch de la section view
1. Doble clic en el hatch → diálogo **HATCH** (Figura 8-9).
2. Seleccionar el pattern deseado del Pattern drop-down.
3. **Scale Factor = 0.5**.
4. **Angle = 5** → Close.

### 4. Detail View
1. Tool **Detail View** (panel CREATE): seleccionar la **top projected view** como padre.
2. Dibujar un **límite circular** en la top view (sobre el "circular feature" del modelo)
   (Figura 8-10) → la detail view se pega al cursor.
3. Colocar la detail view **a la derecha de la hoja, arriba del title block** (Figura 8-11).
4. **Scale = 1:3** → OK.

### 5. Guardar
- File → Save. **Name = c08_Tut_01**. Location → PROJECT **CADCIM** → Save.

## herramientasFaltantes (lo que La Forja necesitaría para reproducir esto)
La Forja hoy es un CAD de **modelado** (sketcher + B-Rep). Este tutorial requiere un
**Drawing workspace** completo que probablemente NO existe:
- **Drawing workspace / documento de plano** con formato de hoja (A4 297×210, Landscape).
- **Standards** (ISO/ASME) y **Third Angle projection** configurable.
- **Base/Parent View** con Orientation (Front) + estilos de aristas (Visible / Visible &
  Hidden) + escala (1:4).
- **Projected View** (proyección ortográfica arrastrando el cursor: top, right, isometric).
- **Section View / Aligned Section View** (línea de sección con snap + hatch automático).
- **HATCH** editable (pattern, scale factor, angle).
- **Detail View** (límite circular + escala 1:3).
- **Marking menu** (clic derecho contextual con Continue/OK).
- Asociatividad plano↔modelo.
- (Ya existe motor de planos `drawing.ts` con HLR 3D→2D según memoria; falta el **workspace
  UI** con estas tools y section/detail views.)
