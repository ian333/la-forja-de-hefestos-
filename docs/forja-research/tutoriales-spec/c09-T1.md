# c09 — Tutorial 1: Holder Clip (chapa / sheet metal)

Fuente: *Autodesk Fusion 360: A Tutorial Approach* (CADCIM), Capítulo 9 "Working with Sheet Metal
Components", Tutorial 1. Extraído LITERAL del texto + Figuras 9-3, 9-4, 9-5, 9-8, 9-11, 9-13.
Tiempo estimado en el libro: 45 min. Nombre de guardado: `c09_Tut_01` en el proyecto CADCIM.

> AVISO IMPORTANTE: este NO es un tutorial de croquis→extrude. Es un tutorial de **CHAPA
> (Sheet Metal workspace)**: base wall + contour flanges + bends automáticos + flat pattern.
> La Forja hoy NO tiene workspace de chapa. Ver `herramientasFaltantes` al final.

## objetivo
Construir el componente de chapa **"Holder Clip"** (Figura 9-3): una base plana con forma de "T"
que se dobla en varias paredes (flanges) formando un puente/abrazadera, con recortes, chaflán,
redondeos y dos barrenos. La chapa tiene **espesor 1 mm**. Se construye con la herramienta
**Flange** (a partir de croquis-contorno) + **Extrude (cut/join)** + **Chamfer** + **Fillet** +
**Hole**. El libro también muestra su **flat pattern** (Figura 9-4).

## setup (parámetros de chapa)
Del texto (Sheet Metal Rules → Edit Rule sobre el nodo "Steel (mm) (Default)"):
- **Thickness (espesor) = 1**
- **Bend radius = 2**  ← esto dice el TEXTO (paso 5).
  - OJO / discrepancia real del libro: la **Figura 9-5** rotula "BEND RADIUS 1 MM". El texto pone 2,
    la figura pone 1. NO lo invento: el libro se contradice. (Corner radius de la figura = 2 mm.)
- Resto de valores: por defecto. Guardar (Save) y cerrar (Close).
- Unidades: mm (no se especifica cambio de unidades; el libro trabaja en mm por defecto).
- No se menciona grid/snap explícito.

## restricciones
El texto NO enumera restricciones explícitas (tangent/equal/symmetric/etc). Los croquis se acotan
directo por dimensiones (ver `cotas`/`medidasFigura`). Las líneas son horizontales/verticales
(implícito por la forma ortogonal). En el paso del 1er flange el libro señala que al seleccionar
una de las dos líneas del croquis, **la otra línea se selecciona automáticamente** por pertenecer
al mismo croquis (no es una restricción de usuario, es comportamiento de Flange). NO inventar más.

## cotas (Sketch Dimensions literales por croquis)
- Base (Fig 9-8): 95, 44, 32, 26, 19, 8, 27, 20.
- 3er contour flange (Fig 9-13): 40 (longitud), 31 (offset).
- Corte / cara nueva / chaflán / redondeos / barrenos: "Refer to Figure 9-5" → ver `medidasFigura`.

## feature3D (operaciones, en orden)
1. **Flange** sobre el croquis de la base → crea el **base wall** (Fig 9-9). OK con defaults.
2. **Flange** (contour) sobre el croquis B → seleccionar una de las 2 líneas del perfil + la
   **arista a la DERECHA** del top face. Defaults → OK. Se crea el bend automático (parámetros del
   Sheet Metal Rules).
3. **Flange** (contour) igual en el otro lado → seleccionar la **arista a la IZQUIERDA** del top
   face. → Fig 9-12 (dos contour flanges).
4. **Flange** (3er contour) con croquis C → **Distance = -27** en el diálogo FLANGE + seleccionar la
   **arista horizontal** del top face. → Fig 9-14.
5. **Extrude (Cut)** con croquis D → **Extent Type = All**, luego **Flip** para invertir la dirección.
   → Fig 9-16.
6. **Extrude (Join)** con croquis E → crea la cara rectangular nueva. Operation = **Join**.
7. **Chamfer** (MODIFY) sobre la cara nueva → dims en Fig 9-5 = **6 X 45°**. → Fig 9-17.
8. **Flange (last)**: seleccionar la **arista inferior** del top face de la base (Fig 9-18) →
   **Distance = 19** → **Flip** dirección → OK. → Fig 9-19.
9. **Fillet** (rounds): crear todos los redondeos. Dims Fig 9-5 = **4X R7**.
10. **Hole** (CREATE panel, pestaña SOLID): crear **dos barrenos**. Dims Fig 9-5 = **Ø8** (y el
    concéntrico **Ø13**, ver nota en medidasFigura).
11. Guardar como `c09_Tut_01`.

## herramientasFaltantes (honesto — La Forja hoy)
Este tutorial es de **CHAPA** y La Forja no tiene ese módulo. Falta prácticamente todo el flujo:
- **Sheet Metal workspace** completo (no existe en La Forja).
- **Sheet Metal Rules / Edit Rule** (espesor + bend radius + relief como parámetros de material).
- **Flange tool** con creación de **bend automático** entre paredes.
- **Contour Flange** (flange a partir de un croquis-perfil sobre una arista) + opción **Distance** +
  **Flip** de dirección + selección de arista.
- **Flat Pattern** (desdoblado del componente de chapa).
- **Chamfer** de sólido (borde) — verificar si La Forja lo tiene; el croquis-chamfer no basta.
- **Hole tool** (barreno paramétrico, incl. concéntrico Ø13/Ø8).
- **Extrude con Extent "All" + Flip + Operation Join/Cut** sobre caras dobladas.
- Seleccionar **cara** y **arista** de un sólido como referencia (sketch plane / edge picking).
- Croquis con inferencia orto (líneas H/V automáticas) — probablemente parcial.

Lo que La Forja SÍ podría cubrir del corazón geométrico: croquis de líneas acotado (Fig 9-8) y un
Extrude básico. Todo lo demás (doblez de chapa) requiere módulo nuevo.

## formaFinal (para verificar)
Abrazadera/clip de lámina de 1 mm: una base en "T" que se dobla hacia abajo formando un **puente**
tipo omega/U con paredes verticales; hay lengüetas laterales dobladas hacia afuera con pie plano,
un recorte central rectangular (muesca), una cara frontal con **chaflán 6×45°**, cuatro esquinas
redondeadas **R7**, y **dos barrenos** (uno Ø8 simple + uno concéntrico Ø13/Ø8). Envolvente
aprox. 95 mm de largo. Coincide con Figura 9-3 (modelo) y Figura 9-4 (flat pattern).
