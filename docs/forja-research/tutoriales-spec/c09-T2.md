## objetivo
Construir un **componente de CHAPA metálica (sheet metal)** — una especie de cubierta/holder
rectangular con cuatro pestañas (flanges) hacia abajo, paredes laterales con orejas taladradas,
ranuras (slots) a lo largo de los dobleces y barrenos. **NO es un extrude/revolve normal**: se hace
con el flujo de chapa: **Base Flange → Flange → Flange (paredes) → Unfold → Extrude Cut + Pattern
→ Refold → Holes**. Al final se generan sus **vistas de plano (drawing views)**.

## setup
- **Workspace**: SHEET METAL (chapa). El libro NO especifica unidades/grid/snap explícitos para
  este tutorial; se asume mm (todas las cotas están en mm).
- Parámetros de chapa dados en la Figura 9-23: **THICKNESS OF SHEET = 1 MM**, **BEND RADIUS = 2 MM**.

## pasosDibujo (LITERAL del texto)

### a. Crear el Base Flange
1. Invocar el workspace **SHEET METAL** y elegir **Create Sketch** del panel CREATE del Ribbon.
2. Seleccionar el **plano XZ** y crear un **rectángulo de 250 x 200 mm** como croquis del base flange.
3. **FINISH SKETCH**. Luego elegir la herramienta **Flange** del panel CREATE → aparece el cuadro FLANGE.
4. Seleccionar el croquis en la ventana gráfica y **OK** para crear el flange (base).

### b. Crear cuatro flanges (las 4 pestañas)
1. Elegir **Flange** del panel CREATE y seleccionar las aristas del base flange (Figura 9-24).
2. Escribir **30** en el edit box **Height**.
3. Pulsar **Flip** para invertir la dirección del flange. Luego **OK** → flange creado (Figura 9-25).

### c. Crear paredes en las aristas (Wall on Edges)
1. Elegir **Flange** del panel CREATE y seleccionar la **arista inferior del flange frontal** (Figura 9-26).
2. Seleccionar la opción **Symmetric** en el drop-down **Full Edge** del cuadro FLANGE.
3. Escribir **75** en el edit box **Distance** y **25** en el edit box **Height**.
4. **OK** → pared lateral creada (Figura 9-27).
5. Repetir para las otras **tres paredes** en las aristas del resto de los flanges. Dimensiones: Figura 9-23.
   Modelo con las cuatro paredes: Figura 9-28.

### d. Crear cortes a través de los dobleces (Cuts Across the Bends)
1. Elegir **Unfold** del panel MODIFY → cuadro UNFOLD, pide entidad estacionaria.
2. Seleccionar la **cara superior** como entidad estacionaria; pide seleccionar los bends a desdoblar.
3. Marcar el check **Unfold all bends** y **OK** (o seleccionar los bends uno por uno). Vista desdoblada: Figura 9-29.
4. Seleccionar la **cara superior** del modelo y elegir **Create Sketch** (panel CREATE, tab SOLID).
   Luego elegir **2-Point Rectangle** del panel CREATE del tab SKETCH y dibujar el croquis del corte
   (Figura 9-30). — *(Es la ranura/slot; dimensiones en Figura 9-23: 10 TYP de ancho, 3 TYP de separación, largo 130.)*
5. Invocar el cuadro **EXTRUDE** y crear el **corte (Cut)**. Modelo con el corte: Figura 9-31.
6. **Pattern** del corte (patrón rectangular a lo largo del borde). Modelo con el patrón: Figura 9-32.

### e. Refold + barrenos
1. Elegir **REFOLD FACES** del Ribbon → la chapa se vuelve a plegar.
2. Crear **barrenos (holes)** en las cuatro paredes. Dimensiones: Figura 9-23. Resultado: Figura 9-33.
3. Guardar como **c09_Tut_02** bajo el proyecto CADCIM.

## feature3D (operaciones)
- **Base Flange** desde rectángulo 250 x 200 (espesor 1 mm, radio de doblez 2 mm).
- **Flange** en 4 aristas: Height **30**, dirección invertida (Flip).
- **Flange** (paredes) en aristas: **Symmetric**, Distance **75**, Height **25** (×4).
- **Unfold** all bends (cara superior estacionaria).
- **Extrude → Cut** del croquis de ranura (2-Point Rectangle) + **Pattern** rectangular.
- **Refold Faces**.
- **Hole** ×4 (Ø5) en las paredes.
