## objetivo
Modelar una especie de **rueda/impulsor (rodete)**: un aro/anillo revolucionado (feature base **Revolve** 360°) con un **cubo central**, más **3 álabes/paletas** curvas creadas con **Loft** (dos secciones elípticas a lo largo de una trayectoria) y luego **Circular Pattern** (3 copias) del loft alrededor del eje.
- Base = Revolve (360°).
- Álabe = Loft entre 2 secciones (elipses) con **Centerline** = la trayectoria.
- Multiplicación = Circular Pattern, Full, cantidad 3.
- Guardar como `c06_Tut_03`.

Modelo final: Figura 6-30. Dimensiones/vistas: Figura 6-31.

## FEATURE 2 — Álabe (Loft entre 2 secciones a lo largo de una trayectoria)

### A) Trayectoria (path) — Figura 6-34
1. Create Sketch → plano **XY**.
2. Cambiar estilo de visualización a wireframe/línea oculta: Display Settings → Visual Style → Wireframe (para ver a través del modelo).
3. Dibujar la trayectoria como en Figura 6-34: un **arco R150** que sube desde cerca del cubo hasta el aro exterior.
4. Finish Sketch.

**cotas del path (Figura 6-34, mm):**
- **R150.00** (radio del arco de la trayectoria)
- 250.00 (distancia horizontal total, del eje al punto exterior sobre el aro)
- 40.00 (offset horizontal del eje al arranque interior del arco)
- 65.00 (altura desde la línea de referencia inferior a la superior)
- 25.00 (altura del extremo exterior del arco respecto a la referencia superior)

### B) Planos de sección (Plane Along Path)
5. Volver a estilo sombreado con aristas visibles.
6. **Plane Along Path** (CONSTRUCT).
7. Seleccionar la trayectoria; arrastrar la flecha a un **extremo** del path → plano normal a la curva en ese extremo. OK.
8. Repetir para crear otro plano normal en el **otro extremo** del path. (Isométrico resultante: Figura 6-35; plano a seleccionar: Figura 6-36.)

### C) Secciones (2 elipses)
9. Sobre el **primer plano de referencia** → Create Sketch → dibujar la **sección elíptica 1** (Figura 6-37).
10. Sobre el **segundo plano de referencia** → dibujar la **sección elíptica 2** (Figura 6-38).
11. Finish Sketch.

**cotas de las secciones (Figuras 6-31 / 6-37 / 6-38, mm):**
- PROFILE 1 (extremo interior, junto al cubo): elipse **10.00** (eje menor / ancho) × **40.00** (eje mayor / alto). (Fig. 6-37 confirma 10.00 y 40.00.)
- PROFILE 2 (extremo exterior, sobre el aro): elipse **80.00** (eje mayor / ancho) × **20.00** (eje menor / alto). (Fig. 6-38 confirma 80.00 y 20.00.)

### restricciones (loft)
- **[NO EN EL LIBRO]** no se listan restricciones explícitas; cada elipse se define por sus dos cotas de eje.

### feature3D (loft)
- Herramienta **Loft** (CREATE, SOLID).
- Profiles = las 2 secciones (seleccionar una por una).
- **Guide Type = Centerline** → seleccionar la trayectoria (path) creada.
- **Operation = Join**.
- Resto de opciones por defecto. OK.
- Resultado: Figura 6-39.

## FEATURE 3 — Circular Pattern del loft
1. **Circular Pattern** (CREATE → Pattern).
2. Pattern Type = **Features**.
3. Object to pattern = el **loft** (desde el timeline).
4. Axis = la **arista circular** del modelo (eje del rodete).
5. Type = **Full**; Quantity = **3**.
6. OK. Resultado final: Figura 6-40 (3 álabes distribuidos 120°).

> La Figura 6-31 (vista superior) confirma la separación **120°** entre álabes.

## herramientasFaltantes (honesto — qué necesita La Forja)
- **Revolve 360°** con eje/centerline del propio croquis (probablemente ya existe).
- **Arco por radio / 3-point arc** en el sketcher (R300, R150) — verificar que el solver soporte arco tangente acotado por radio.
- **Elipse acotada por sus dos ejes** en el croquis 2D (PROFILE 1/2) — herramienta ellipse.
- **Plane Along Path** (plano normal a una curva, en sus extremos) — geometría de referencia; probablemente FALTA.
- **Loft con Guide Type = Centerline** (loft guiado por una trayectoria, no solo entre secciones) — FALTA casi seguro.
- **Circular Pattern de features** alrededor de una arista/eje, opción Full + cantidad — verificar soporte de patrón de FEATURE (no de cara).
- Estilo de visualización **Wireframe** para dibujar a través del sólido (ayuda, no bloqueante).

## formaFinal (para verificación)
Un **rodete/impulsor** tipo rueda: un **aro/anillo** grueso (Ø448 exterior, cara exterior curva R300 de 188 de alto) con un **cubo cilíndrico central** (escalonado Ø150/Ø97/Ø85 con un pequeño chaflán 45°). Del cubo al aro nacen **3 álabes** curvos, torcidos, distribuidos a **120°**: cada álabe es un loft que va de una elipse alta y angosta (10×40, junto al cubo) a una elipse ancha y baja (80×20, sobre el aro), siguiendo un arco R150 que sube. Se ve como una turbina/hélice de 3 aspas dentro de un anillo (Figura 6-30).
