# c06 — Tutorial 4 (Fusion 360: A Tutorial Approach, CADCIM)

> Extracción LITERAL para reproducir el tutorial por clicks en La Forja.
> Fuente: `c06_fusion_360.txt` (líneas 242-296) + figuras (Fig 6-41 = imagen 207).
> Tiempo estimado del libro: 45 min.

## ⚠️ Aviso importante
Este NO es un tutorial de croquis + extrusión. Es un tutorial de **SCULPT / FORM (T-Spline / freeform)**.
Se construye deformando una caja primitiva T-Spline, no dibujando un croquis 2D acotado.
Por eso NO hay `pasosDibujo`, ni `restricciones` de croquis, ni `cotas` de Sketch Dimension.
El libro tampoco pide generar planos (drawing views).

## objetivo
Crear el modelo de la Figura 6-41: una **caja redondeada tipo T-Spline** (freeform) que se
crea con una primitiva de caja en el espacio Sculpt, se le aplica simetría espejo, se le
insertan aristas, se acuartelan (crease) y se editan para deformarla. Modelo final = Fig 6-48.

Método: **Create Form (Sculpt)** → **Box primitive** → **Mirror-Internal** → **Insert Edge** →
**Crease** → **Edit Form** → **Finish Form** → **Fillet 2 mm**.

## setup
- El libro NO especifica unidades ni grid/snap en este tutorial (asumir mm por defecto del proyecto).
- Se entra al espacio **Sculpt** con la herramienta **Create Form** (panel CREATE del Ribbon);
  se invoca el workspace contextual FORM.

## pasos (LITERAL, en orden)

### A. Entrar a Sculpt
1. Elegir **Create Form** (panel CREATE del Ribbon) → se invoca el workspace contextual FORM.

### B. Crear la caja (Box primitive)
1. Elegir la herramienta **Box** (panel CREATE) → aparece el cuadro de diálogo BOX (Fig 6-42);
   pide seleccionar un plano o cara planar.
2. Seleccionar **XZ Plane** en el BROWSER → pide el punto central de la caja.
3. Seleccionar el **origen** como punto central → pide el tamaño del rectángulo.
4. Escribir **50** en Length (longitud), Tab, escribir **40** en Width (ancho).
5. Tab otra vez para bloquear las dimensiones → aparece el edit box **Height** en la ventana gráfica.
   - (Opciones informadas por el libro: Width Faces, Height Faces, Length Faces = nº de caras por
     ancho/alto/largo; Direction = dirección de extrusión de la primitiva.)
6. Escribir **100** en **Height**. Escribir **6** en **Height Faces**.
7. Dejar el resto por defecto → **OK**. (Fig 6-43 = modelo tras crear la caja.)

### C. Crear el espejo (Mirror - Internal)
1. Elegir **Mirror - Internal** (panel SYMMETRY del Ribbon) → diálogo MIRROR - INTERNAL;
   pide la cara del lado maestro.
2. Seleccionar la **cara frontal** de la caja (Fig 6-44) → pide la cara del lado espejo.
3. Seleccionar la **cara trasera** de la caja → aparece una línea simétrica verde (Fig 6-45).
4. **OK**.

### D. Insertar aristas (Insert Edge)
1. Elegir **Insert Edge** (panel MODIFY) → diálogo INSERT EDGE; pide seleccionar aristas.
2. Seleccionar la arista de la caja (Fig 6-46).
3. Asegurar que **Both** esté seleccionado en el drop-down **Insertion Side**.
4. Dejar el resto → **OK** (se crean aristas a ambos lados de la arista T-Spline seleccionada).
5. Igual, insertar las demás aristas a ambos lados de la línea simétrica.

### E. Acuartelar y editar aristas (Crease + Edit Form)
1. Elegir **Crease** (panel MODIFY) → diálogo CREASE; pide aristas y vértices.
2. Seleccionar las aristas del paso anterior → **OK** (Fig 6-47 = modelo solo con crease).
   - Nota del libro: seleccionar aristas de UN solo lado de la línea simétrica; el crease se
     refleja automáticamente al otro lado al dar OK.
3. Elegir **Edit Form** (panel MODIFY) → diálogo EDIT FORM; pide aristas, vértices o caras.
4. Seleccionar TODAS las aristas acuarteladas con **CTRL** → aparece el triad y el edit box **X Distance**.
5. Escribir **10** en **X Distance** (o arrastrar la flecha del triad en dirección X).
6. **OK** (Fig 6-48 = modelo final).
7. Elegir **Finish Form** del Ribbon para salir del workspace SCULPT.
8. Agregar **fillet de 2 mm** a las aristas acuarteladas (creased).

### F. Guardar
1. **Save** (File / Application menu) → diálogo Save.
2. Nombre: **c06_Tut_04**.
3. Click en la flecha abajo a la derecha del Location → se expande el diálogo.
4. Seleccionar proyecto (o New Project).
5. **Save**.

## feature3D (operaciones)
- Box primitive (T-Spline): 50 (length) × 40 (width) × 100 (height), Height Faces = 6, en XZ plane centrado en origen.
- Mirror - Internal: cara frontal ↔ cara trasera.
- Insert Edge: Insertion Side = Both.
- Crease: sobre aristas insertadas (se auto-espeja).
- Edit Form: X Distance = 10.
- Finish Form.
- Fillet = 2 mm en aristas acuarteladas.

## formaFinal
Un **prisma/caja T-Spline redondeada**, más alto (100) que su base (50×40), con las aristas
verticales acuarteladas y luego jaladas 10 mm en X (deformación de la superficie freeform),
simétrica adelante-atrás, y con las aristas acuarteladas suavizadas por un fillet de 2 mm.
Aspecto: una barra/lingote redondeado de esquinas suaves (Fig 6-41 / 6-48).

## herramientasFaltantes (honesto — La Forja probablemente NO tiene)
La Forja es un CAD B-Rep (croquis→feature). Este tutorial es del **espacio Sculpt / T-Spline**, que es
un paradigma DISTINTO (malla de subdivisión / freeform). Muy probablemente falta TODO esto:
- **Espacio Sculpt / Create Form (workspace de T-Splines / superficies de subdivisión).**
- **Box primitive** de T-Spline (con Length/Width/Height Faces).
- **Mirror - Internal** (simetría interna del cuerpo T-Spline).
- **Insert Edge** (con Insertion Side Both).
- **Crease** (acuartelar aristas de T-Spline, con auto-espejo).
- **Edit Form** (manipulación directa de caras/aristas/vértices con triad + X Distance).
- **Finish Form** (convertir T-Spline a B-Rep).
- **Fillet 3D de aristas** sobre el sólido resultante.

Recomendación: si La Forja no tiene motor de T-Splines/subdivisión, este tutorial NO es reproducible
por clicks tal cual; requeriría implementar un módulo Sculpt separado. No es un candidato bueno para
el pipeline croquis→extrude actual.
